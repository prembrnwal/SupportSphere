# 🛡️ SupportSphere — Modern Support Desk Frontend

SupportSphere Frontend is built using **React 18 + TypeScript + Vite + Tailwind CSS + Zustand + React Query**.

For full project documentation, backend REST API details, and deployment guides, please see the root [README.md](../README.md).
